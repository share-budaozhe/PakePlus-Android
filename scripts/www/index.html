⚡ dBm 速记

0 dBm = 1 mW这是所有 dBm 的锚点

🎯 实战心算示例

例1：800mV 检波电压 → 多少 dBm？ P = V²/R = 0.8²/50 = 0.0128W = 12.8mW；dBm = 10×lg12.8 ≈ 11.07 → ≈ +11 dBm（口算：12.8mW 比 10mW 略大，比 20mW 小，所以 10~13dBm 之间）
例2：28.6W 峰值，占空比 0.1%，平均多少？ 28.6W × 0.001 = 0.0286W = 28.6mW → 平均功率 ≈ 28.6mW（口算：除以 1000）
例3：30dB 衰减，功率降多少倍？ 10^(30/10) = 10³ = 1000 倍（口算：30dB = 3×10dB = 10×10×10）
例4：5GHz、增益10dB，天线口径多大？ λ = 3×10⁸/5×10⁹ = 0.06m；Ae = 10×0.06²/4π ≈ 28.6 cm²（口算：0.06²=0.0036，×10÷12.6≈0.00286m²）
例5：功率密度 1000W/cm² 在 28.6cm² 天线上收多少功率？ P = S×Ae = 1000 × 28.6 = 28600W = 28.6kW（口算：直接相乘）

💡 心算口诀

功率 dB 规律+3dB ≈ ×2，+10dB = ×10，每 +10dB 加一个零；−3dB ≈ ÷2，−10dB = ÷10
dBm 锚点记住 0dBm=1mW、30dBm=1W 两个锚点，其余加减 10 或 3 推算
占空比重频×脉宽，1kHz×1μs=0.1%；平均功率 = 峰值 × 占空比

📐 天线与口径

有效口径Ae = G·λ² / 4π　（G 为线性增益，λ 为波长）
增益(dB) → 线性增益G = 10^(GdB/10)
波长与频率λ = c / f，c = 3×10⁸ m/s；例：5GHz → λ=6cm，10GHz → λ=3cm
功率密度 → 接收功率P接收 = S × Ae　（S 为功率密度 W/m²）
单位换算1 W/cm² = 10⁴ W/m²；1 mW/cm² = 10 W/m²

⚡ 功率与 dBm

电压 → 功率P = V²/R；50Ω 下 P = V²/50
功率 → dBmPdBm = 10·lg(P[mW])
dBm → 功率P[mW] = 10^(PdBm/10)
dB → 倍数功率比 = 10^(dB/10)；电压比 = 10^(dB/20)
功率密度动态(dB)10·lg(Smax/Smin)（功率类量纲，用 10·lg）

🔗 链路预算

总衰减A总 = A₁ + A₂ + … + Aₙ（各级 dB 直接相加）
衰减后功率Pout = Pin − A总（dBm 相减）
衰减倍数Pout/Pin = 10^(−A/10)；30dB → ÷1000，20dB → ÷100
自由空间损耗FSL(dB) = 20·lg(d) + 20·lg(f) + 92.45（d:km，f:GHz）
弗里斯传输Pr = Pt + Gt + Gr − FSL（dB 形式）

⏱ 脉冲参数

占空比D = PRF × τ（τ 为脉宽，秒）
平均功率Pavg = Ppeak × D
单脉冲能量E = Ppeak × τ
峰值/平均差(dB)10·lg(1/D)；D=0.1% → 相差 30dB

🔎 检波器

动态范围DR = Pmax − Pmin（dB）
输入窗口上限(饱和) − DR ≤ Pin ≤ 上限(饱和)
检波电压 → 功率P = V²/R（V 为检波直流输出电压）

📏 驻波与反射

驻波比 → 反射系数|Γ| = (VSWR−1)/(VSWR+1)
回波损耗RL(dB) = −20·lg|Γ|
失配损耗ML(dB) = −10·lg(1−|Γ|²)
VSWR=1.3 时|Γ|≈0.13，回波损耗≈17.7dB，失配损耗≈0.075dB

🌡 噪声与灵敏度

热噪声功率Pn = kTB；k=1.38×10⁻²³，B 为带宽
噪声系数级联(Friis)F = F₁ + (F₂−1)/G₁ + (F₃−1)/(G₁G₂) + …
灵敏度Smin(dBm) = −174 + 10·lg(B) + NF + SNR
